# Remon mobile app build

The repository has a Capacitor configuration for the Remon marketplace.

## Build an Android test app

1. Open the repository's **Actions** tab on GitHub.
2. Choose **Build Remon Android app**.
3. Press **Run workflow**.
4. Wait for the workflow to finish, then download:
   - `remon-android-debug-apk` to install and test on an Android phone.
   - `remon-android-aab` for the Android App Bundle build output.

The debug APK is for testing. The release AAB generated by this workflow is not signed for Play Store publication yet. Before release, configure secure signing credentials in GitHub Actions secrets and sign the AAB. Never commit a keystore or its passwords to the repository.

## Google Play

Publishing requires a Google Play Console developer account, a signed AAB, store listing assets and text, privacy policy, data safety declarations, app access instructions, and any required testing/review steps. Store acceptance cannot be guaranteed in advance.

## Apple App Store

iOS compilation and submission require macOS/Xcode and an Apple Developer Program account. App Store distribution also requires signing/provisioning, App Store Connect configuration, privacy disclosures, and review. Do not commit Apple certificates or private signing credentials to this repository.

## Before public release

- Test Google sign-in and session persistence inside the native app; web OAuth flows may need native OAuth configuration.
- Review Firebase Security Rules and administrator permissions.
- Provide a privacy policy and a working account deletion process.
- Verify all external links, payments, advertising, and user-generated content comply with each store's policies.
