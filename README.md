- اشتراك تجار مع **3 أيام مجانية**

- ميزة **تحدي السؤال** (جغرافيا + أسئلة إسلامية)
- أيقونة ذكاء اصطناعي لطيفة
- الآية الكريمة في أعلى كل صفحة
- رقم شام كاش ورقم الواتساب مدمجان

## طريقة الرفع على Vercel

1. ارفع المجلد كاملاً على GitHub
2. ادخل إلى [vercel.com](https://vercel.com)
3. اضغط New Project → Import من GitHub
4. اختر المستودع واضغط Deploy
5. الموقع سيعمل مباشرة
